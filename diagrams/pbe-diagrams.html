Jane Street protocol emulator ASIC · pbe_v1 · feature/ethernet

Programmable Bit Engine

Two small engines run programs that drive, release and read eight pins. Every protocol is a program loaded at run time: UART, SPI (controller and peripheral), quad SPI, I2C (controller with SMBus PEC, and target), 1-Wire, Modbus RTU, WS2812, a USB low-speed device, a CAN 2.0A node, JTAG, SWD, PS/2, HDLC, a GPIO expander, a logic analyser and 10BASE-T Ethernet. The engines share no protocol blocks, only general helpers: a CRC unit (any polynomial up to 32 bits), parity, timeouts, a line coder (NRZ, NRZI, Manchester, bit stuffing, differential pair) and a bit-synchronous coder for CAN-style buses. Each engine runs from its own 256-word SRAM. 8×4 Tiny Tapeout tiles, IHP 130 nm, 60 MHz.

4 · Registers

Each engine has 16 registers: engine 0 at 0x10–0x1F, engine 1 at 0x20–0x2F.

SlotRegisterHolds
+0, +1CLKDIVTick = one clock every CLKDIV + 1 clocks (with a line coder on: the bit time)
+2PIN_BASEFirst pin this engine's programs use
+3JMP_PINPin tested by JMP PIN_HI / PIN_LO
+4SHIFTOSR and ISR bit order (LSB or MSB first)
+5START_PCThe program's first word in this engine's SRAM (0–255); its jumps are relative to it
+6FIFO dataWrite: TX FIFO; read: RX FIFO
+7—Free
+8FLAG_BASEFirst of the 8 flags this engine sees (reset: 0 for engine 0, 4 for engine 1)
+9, +ACRC_POLYWrite: CRC polynomial bits 15..0, top term implied. Read: the CRC's current value
+BCRC_CFGWidth − 1, initial value all ones, reversed output, fed by OUT bits, fed by IN bits
+C, +DTIMEOUTTicks a blocked WAIT / PULL / PUSH may wait; 0 = forever
+ELINE_CFGTIMEOUT_PC (where a timeout jumps), no parity (8N2), odd parity
+FSTATUSRead: parity error, CRC ok, timeout, RX overflow, line error, arbitration lost, bit error, frame sent. Write: restart the CRC or clear any of the sticky bits

A second page per engine (engine 0 at 0x30, engine 1 at 0x40) holds the line coder, CAN and wide-CRC settings.
